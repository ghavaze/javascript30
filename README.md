## 📌 Project Overview

This repository contains my implementation of the JavaScript30 challenge created by Wes Bos. The goal of this project is to develop practical skills in pure JavaScript (Vanilla JS) by building 30 small applications.

## 🎯 Goals

- Improve my JavaScript skills
- Learn through practice and solving real problems
- Build a habit of consistent coding
- Document my progress
- Gain practical experience working with Git and version control systems

## 💡 Assumptions

- Focus on pure JavaScript (no frameworks)
- Work on a pre-built visual layer (**HTML** + **CSS**) to fully concentrate on logic
- Solve problems independently and build solutions consciously
- Consistently document progress within the repository

## 📝 Summary

After completing JavaScript30, I realized just how much you can do with JavaScript alone. From simple projects like a drum kit or a clock, through canvas, localStorage, and geolocation, all the way to speech recognition and synthesis. All without frameworks.

Although some of the projects posed a significant challenge for me (I didn’t fully understand how they worked), after spending time figuring them out, I can say that those were the moments that taught me the most. They didn’t just reinforce what I already knew; they exposed me to areas I had previously avoided.

What I took away from this:
- Greater ease in working with the **DOM**, events, browser APIs, etc.
- A better sense of the limits of pure JavaScript
- The habit of coding regularly and documenting my progress
- Patience with topics that I don’t yet fully understand
